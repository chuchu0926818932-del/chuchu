# 2026-11-03 每日短影音企劃設計

## 目的

新增 30 條可直接用於短影音企劃網站的原創企劃：職涯／事業導向的女性成長、非金融建議的金錢價值觀，以及不標籤孩子的親子關係各 10 條。

## 範圍與限制

- 建立 `D20261103-01` 至 `D20261103-30`，完整填寫 Topic、故事與三層欄位。
- 女性成長只涵蓋職場界線、升遷與談薪、職涯轉換、專業定位、創業／工作自信、協作／領導。
- 金錢內容不提供投資、借貸或金融商品建議；親子內容不貼標籤、不承諾行為改變。
- title、hook、scene、explain、singleCta 對網站題庫及桌面 Markdown/XLSX 都必須嚴格去重。
- 八種外層版型需平均輪替，並建立日期命名 Markdown 與 XLSX；既有退役版本不可修改。

## 方案

沿用已驗證的日期批次、匯出器、工作簿與驗證器結構。先用測試鎖定資料約束，登錄新資料後產生兩種交付檔，最後做全庫、全桌面與匯出對等檢查。
